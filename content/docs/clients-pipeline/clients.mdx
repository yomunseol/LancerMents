Clients is the address book for the work. Every client record also holds the notes, deals, and invoices linked to that account.

## Add a client

1. Open **Clients** and choose **Add client**.
2. Enter a name. This field is required.
3. Add an email if you bill through it. Invalid addresses are rejected before saving.
4. Add an address if you want the Studio map to place the client.
5. Choose **Create**. The record saves first, then the address lookup runs in the background.

## Find a client

- Type in the search field to filter by name or email.
- Use the **All**, **Active**, and **Blocked** chips to narrow the list.
- On desktop, select a row to open the drawer. On mobile, tap the card.
- Select the client name to open the full detail page.

## Work inside a client

The detail page and drawer show contact details, the address, linked notes, deals, and invoices. The map appears on the Studio plan once the address has coordinates. Use **Open in Google Maps** for directions.

## Block a client

Blocking marks the record as inactive without deleting anything. Choose **Block**, then confirm with **Sure?**. Use **Unblock** when work resumes. Existing notes and invoices stay attached.
