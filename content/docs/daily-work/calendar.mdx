The calendar reads the same due dates you set on tasks. It is a planning view, so new tasks are still created on the daily grid.

## Move through months

1. Open **Calendar** from the sidebar.
2. Use the left and right arrows beside the month name.
3. The current month loads with every task that has a due date.

## Read a day

1. Select any day in the grid.
2. The panel below lists every task due that day.
3. Completed tasks are shown with a line through the title.
4. Select another day to move the panel.

Days with work show a count. Empty days stay quiet, so the month is easy to scan.
