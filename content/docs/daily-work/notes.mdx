Notes are a scratchpad, not a document editor. There are no folders or page trees, which keeps capture fast.

## Create a note

1. Open **Notes** from the sidebar.
2. Choose **New scratch note**.
3. Type a title and the note body.
4. Changes save when you leave the field. A saved confirmation appears at the top of the page.

## Read and edit

The list on the left holds every note in the workspace. Select one to edit it. Notes with a pinned flag appear in a separate pinned section above the main list.

## Linked notes

When a note is linked to a client, it appears in that client's detail view and drawer. That keeps meeting notes and client research next to the account they belong to.
