Spreadsheet appears on Expert and Business plans. During the public beta the page is a preview: you cannot create, edit, or import a sheet yet.

## What is available

- The module opens from the sidebar on eligible plans.
- Lower plans see an upgrade card.
- The planned grid is meant for budgets, project trackers, and bulk data that should stay inside LancerMents.

## Keep trackers today

1. Open **Notes**.
2. Create one note per tracker, such as a monthly budget or a project checklist.
3. Use short lines and clear labels so the note stays readable.

When the grid ships, the same information can move into a sheet without changing how you work.
